# Architectural Decision Records (ADRs)

This directory stores all formal Architectural Decision Records (ADRs) for Sagar OS.

## ADR Index
See the root [DECISIONS.md](../../DECISIONS.md) file for the comprehensive index of all decisions.

## Creating an ADR
1. Copy the structure outlined in [docs/standards/DOCUMENTATION.md](../standards/DOCUMENTATION.md).
2. Name the file `XXXX-<slug>.md` where `XXXX` is a 4-digit sequential zero-padded number.
3. Update [DECISIONS.md](../../DECISIONS.md) with a reference and summary.
