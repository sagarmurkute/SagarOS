# OS Installer Configuration (`distro/installer/`)

This directory contains recipes, branding profiles, and configuration modules for the Sagar OS live system installer.

## Planned Scope
- Installer framework configurations (e.g., Calamares modules or preseed automation).
- Partitioning presets (Btrfs subvolume layout, swap-on-zram, EFI system partition sizing).
- Post-install setup hooks and locale/keyboard configuration scripts.
