# Bootloader & Firmware Configurations (`distro/boot/`)

This directory contains configuration files, themes, and stubs for the Sagar OS boot environment.

## Planned Scope
- GRUB 2 configuration templates, EFI boot stubs, and `systemd-boot` loader definitions.
- Kernel command-line presets (`cmdline`) for silent, fast UEFI booting.
- Plymouth boot splash configuration and early KMS hooks.
