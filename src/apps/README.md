# Sagar OS First-Party Applications (`src/apps/`)

This directory will contain native first-party applications developed to provide a focused, distraction-free user experience.

## Planned Applications (Phase 4)
- `sagar-settings`: Unified graphical control center communicating with `sagar-configd`.
- `sagar-terminal`: Hardware-accelerated, lightweight terminal emulator.
- `sagar-files`: Fast, clean file manager adhering to modern freedesktop standards.
- `sagar-monitor`: System performance, process manager, and hardware health monitor.

## Standards
- Strict application sandboxing (Landlock / seccomp / unprivileged namespaces).
- Consistent human interface guidelines (HIG).
- No implementation code is present during Phase 0.
